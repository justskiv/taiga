{{- /* Fold — a minimal inline disclosure. A quiet one-line summary that expands into a panel of markdown, with no border or background, so it reads as part of the prose (not a boxed widget). General-purpose; a "there is also a video version" note is just one use of it. {{< fold icon="video" title="There is a [video version](https://…)" >}} …markdown body… {{< /fold >}} Params: icon= leading glyph, one of the keys in $icons below — video · info · tip · book · code · terminal · warning · star · link · note. Default "info"; use "none" to omit it. title= summary line, rendered as INLINE markdown (links work). Required. more= collapsed toggle label. Default "Подробнее". less= expanded toggle label. Default "Свернуть". open= "true" to render already expanded. Default collapsed. size= "note" | "section", overriding the automatic pick below. TWO REGISTERS. A three-line aside and an optional chapter of several screens are the same component doing two different jobs, and they want different weight: "note" keeps the quiet summary of the original, while "section" sets the summary at reading size and closes the panel with an explicit "Свернуть" so the reader is not sent back up to find the toggle. The pick is made from the body's length rather than asked of the author — the register follows what was written, and cannot drift when a paragraph is added later. $threshold is calibrated against the folds this site actually has: a one-paragraph pointer (311) and a two-paragraph "there is also a video version" (711) stay notes, while an aside carrying a widget (1022), a table (1574) or the four-screen ликбез (9165) becomes a section. Below it a closing row is noise; above it the reader is scrolling and needs one. Counted in RUNES, not bytes: len() counts Cyrillic twice and would push every second Russian aside a register up. Styling + the height-reveal animation live in assets/css/22-fold.css (.fold …); the height animation needs interpolate-size, set on :root in 00-tokens.css. The .fold-rail button is the invisible hit strip over the rail — see 22-fold.css for why it is mouse-only and out of the tab order. One tiny once-per-page script does three things: it keeps a link inside the summary from toggling the panel; it collapses the fold from the closing row or from the rail; and when the summary has scrolled off the top it brings the reader back to it (collapsing four screens from the bottom otherwise teleports them into an unrelated paragraph — while a fold that fits on screen must not be yanked to the top for no reason). That return scroll has three things to get right, each of which was a visible miss on the way here: the position and the scroll offset are BOTH read before `open` changes, or a clamped scrollY lands the page somewhere else; scroll-behavior is forced to `auto` for the call, because 01-base.css sets `smooth` on :root and a smooth scroll is still travelling while the panel shrinks under it, so it aims at a target that has already moved; and the landing subtracts the height of the sticky header, which an upward scroll brings back out (modules/header.js) right on top of the summary we just returned to. Focus then moves to the summary: the control that was carrying it has just been collapsed out of the page, and the summary is the same switch in its other position — the keyboard lands where the reader would press next, with preventScroll so the move cannot undo the scroll above. Collapsing arms window.Taiga.holdScroll() first — the public entry of modules/scrollhold.js — because the browser's own scroll anchoring would otherwise compensate for the collapse and fight the scroll we do (the module's "BEFORE, NOT AFTER" rule; neither the closing row nor the rail is a , so nothing arms it for us). A click that ended a text selection is ignored: the strip sits in the left margin, where a drag to select a paragraph naturally starts. Without JS the only cost is that such a link click also toggles and that the closing row collapses without the scroll — the component still works. */ -}} {{- $icons := dict "video" `` "info" `` "tip" `` "book" `` "code" `` "terminal" `` "warning" `` "star" `` "link" `` "note" `` -}} {{- $name := .Get "icon" | default "info" -}} {{- $title := .Get "title" -}} {{- if not $title }}{{ errorf "fold: missing required param title= (page %s)" .Page.Path }}{{ end -}} {{- if and (ne $name "none") (not (index $icons $name)) }}{{ warnf "fold: unknown icon %q (page %s)" $name .Page.Path }}{{ end -}} {{- $more := .Get "more" | default "Подробнее" -}} {{- $less := .Get "less" | default "Свернуть" -}} {{- $open := eq (.Get "open") "true" -}} {{- $threshold := 900 -}} {{- $size := .Get "size" -}} {{- if $size -}} {{- if not (in (slice "note" "section") $size) -}} {{- errorf "fold: size=%q must be note or section (page %s)" $size .Page.Path -}} {{- end -}} {{- else -}} {{- $size = cond (gt (strings.RuneCount .InnerDeindent) $threshold) "section" "note" -}} {{- end -}}
{{- if and (ne $name "none") (index $icons $name) -}} {{- end -}} {{ .Page.RenderString $title }} {{ $more }}{{ $less }}
{{ .Page.RenderString (dict "display" "block") .InnerDeindent }} {{ if eq $size "section" }}{{ end }}
