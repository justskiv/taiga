{{- /* One bar of {{< bars >}} (a plain one, or one of a group): its name, the bar with its value at the end, and a note after it. The value and the note are rendered Markdown, so `code` in a cell stays code. Text order is reading order — name, value, note — so a screen reader and a feed reader get a clean sentence; the bar itself is a sized box carrying the value, nothing to announce. The label sits inside the bar's end unless the bar is too short for it. That is guessed here for a ~300px track (7px a mono character, 16px of padding) and measured on the page by modules/barsfit.js, which moves the class as the column narrows or widens. In a whole (whole="100") the bar runs the full track and its value is the part marked at its end: the label sits inside that part, and the guess is made for the part, not the bar. In a tab of grouped bars (fill: p1 solid, p2 hatched, p3 washed) the column is told by its fill and named by the key, so its name is kept for a screen reader only; the cell is printed at the bar's tip and its note after it, the way a stack prints its total — never inside a washed or hatched fill, so nothing to guess here. Takes dict "page" "name" "sub" (name is a column's short name, printed plain) "val" (dict text note v) "big" (the scale) "c" (colour role) "row" (dict i) "marks" (the rows to draw full) "whole" (bool) and, optionally, "fill". */ -}} {{- $p := .page -}} {{- $v := .val -}} {{- $c := .c -}} {{- $marked := false -}} {{- if and (not .sub) .marks -}} {{- if in .marks (string .row.i) }}{{ $marked = true }}{{ else }}{{ $c = "ghost" }}{{ end -}} {{- end -}} {{- $name := cond .sub (htmlEscape .name) (string ($p.RenderString .name)) -}} {{- $fill := .fill | default "" -}} {{- $chars := strings.RuneCount $v.text -}} {{- $cls := slice "bars-r" -}} {{- if $marked }}{{ $cls = $cls | append "is-mark" }}{{ end -}} {{- $lane := "" -}} {{- if and $v.v .whole -}} {{- $cut := div (math.Round (mul (div (math.Abs $v.v.v) .big) 10000)) 10000.0 -}} {{- if lt (mul $cut 300) (add (mul $chars 7) 16) }}{{ $cls = $cls | append "is-out" }}{{ end -}} {{- $lane = printf "%s" $cut ($p.RenderString $v.text) -}} {{- else if and $v.v $fill -}} {{- $f := div (math.Round (mul (div (math.Abs $v.v.v) .big) 10000)) 10000.0 -}} {{- $lane = printf "%s" $fill $f ($p.RenderString $v.text) -}} {{- else if $v.v -}} {{- $f := div (math.Round (mul (div (math.Abs $v.v.v) .big) 10000)) 10000.0 -}} {{- if lt (mul $f 300) (add (mul $chars 7) 16) }}{{ $cls = $cls | append "is-out" }}{{ end -}} {{- $lane = printf "%s" $f ($p.RenderString $v.text) -}} {{- else -}} {{- $cls = $cls | append "is-na" -}} {{- $lane = printf "%s" ($p.RenderString ($v.text | default "—")) -}} {{- end -}} {{- with $v.note }}{{ $lane = printf "%s%s" $lane ($p.RenderString .) }}{{ end -}} {{- return printf "
\n%s\n%s\n
\n" (delimit $cls " ") $c $c $chars (cond (ne $fill "") "bars-nm vh" "bars-nm") $name $lane -}}
