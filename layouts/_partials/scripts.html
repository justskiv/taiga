{{- /* codapi — the engine behind a runnable snippet — on the pages that have one. {{< run >}} raises a flag on .Page.Store and this reads it back: scripts.html renders after the main block, so the content has already been through the shortcode by the time we get here. A page with no snippet loads nothing. Served from the theme rather than a CDN (assets/vendor/codapi/), so the version is pinned in one place, the file is fingerprinted with an integrity hash like the rest of the bundle, and a guide is not one third-party outage away from a dead Run button. A site upgrades by dropping its own assets/vendor/codapi/snippet.js over the theme's. No stylesheet beside it: codapi's own only lays the parts out, and the theme writes those rules itself (25-code-editor.css). `defer` is safe both ways — modules/codeedit.js mounts on a snippet that is already upgraded or waits for its `load` event, whichever happens first. */ -}} {{- if .Store.Get "codapi" -}} {{- with site.Params.codapi }}{{ with .url }} {{- end }}{{ end -}} {{- /* `with`, not a bare errorf and carry on: errorf lets the template keep running, and the concat below would then fail on a nil resource with a message about slices that says nothing about codapi.
