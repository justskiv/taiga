Everything around it (a card, a hairline row, a popover) differs; this does not, so the state machine in modules/newsletter.js can be written once against .nl-unit (form + promise line + status line). Context: a dict note — the promise line under the field. Optional: no note, no line. id — id for the unit (the subscribe page uses "form", so the popover's footer link can land the cursor in the field). place — short slug naming the placement, unique within one page. It becomes the field's id, so `label[for]` has something to point at. Callers that can repeat on a page (the two shortcodes) mix their .Ordinal in; the once-per-page placements pass a bare word. with its own labelled field. The label is visually hidden (.nl-vh), NOT replaced by aria-label: an aria-label names the field for a screen reader but leaves the managers nothing to pair with. The honeypot is a real, named field, hidden by a CLASS rather than an inline style — part of the bot population skips anything inlined as hidden and fills everything else. It is out of the tab order and out of the a11y tree, so a keyboard or a screen reader never meets it. */ -}} {{- $note := .note -}} {{- $fid := printf "nl-email-%s" (anchorize (.place | default "form")) -}}
