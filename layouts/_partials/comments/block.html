Renders nothing at all on a site with the feature off, or on a page that opted out with `comments: false` in front matter. `ne .Params.comments false` and not `| default true`: in Hugo `false` is an empty value, so `default` would hand `true` straight back to the page that asked for silence. The thread is OPEN — no button in front of it. What is withheld is the engine's bundle: modules/comments.js fetches it once the reader gets within 900 px of this block, and until then the section is these few tags and nothing else. No script, no stylesheet, no socket, no request. `id="comments"` is not decoration. The whole stylesheet hangs off it: the engine's own rules run to (0,5,0) and reach for !important, and an id puts every rule here at (1,x,y), out of that fight for good. Renaming it silently unstyles the widget — 29-comments.css says so too. The header is rendered here rather than injected by the module so that it is on the page in the first paint, before any of the engine exists. The count beside it stays empty until the widget reports one: an empty thread and an unloaded one look identical from the outside, and «пока пусто» is a claim, not a placeholder. Attributes, and why each one is there: no-fonts the engine otherwise pulls Source Sans Pro from its own origin and argues with the page's Inter. theme light/dark, printed from the palette the server chose; modules/comments.js keeps it in step afterwards. It is the ONLY attribute that may change at run time — `lang` and `css-override` reinitialise the widget and throw away a half-written comment. page-id the thread's identity. Stated explicitly from RelPermalink rather than left to the engine's `location.pathname`, so a reader arriving at the same page without its trailing slash lands in the same thread. `auto-init` is absent on purpose: the element upgrades and starts itself the moment the injected bundle lands, so a second switch would only be one more thing to keep in step. `lang` is absent too — the engine reads and ships every translation in its binary. data-pagefind-ignore: comments are not the article, and a search for a word someone used in a reply must not answer with the guide. */ -}} {{- $c := partialCached "comments/cfg.html" . .Language.Lang -}} {{- if and $c.enable (ne .Params.comments false) -}}
