## Код {#code}

Go подсвечивается сервером (Chroma в цветах палитры):

```go
type Point struct {
	X, Y int64
}
func dist(a, b Point) int64 { return (a.X-b.X)*(a.X-b.X) }
```

С подписью файла и подсветкой строки (`{label=… hl_lines=[2]}`):

```go {label="runtime/malloc.go (упрощено)" hl_lines=[2]}
func mallocgc(size uintptr) unsafe.Pointer {
	c := getMCache()          // горячий путь — без блокировок
	return c.alloc(size)
}
```

Остальные подсвеченные языки носят те же роли — синий у структурного имени,
медный у числа, свой тон у строк, приглушённый курсив у комментария:

```json
{
  "items": [
    {"price": 123, "shipped": true},
    {"price": 101}  // хвостовой комментарий допустим
  ]
}
```

```bash
export GODEBUG=schedtrace=1000
go build ./... && ./app --addr "$HOST:8080"   # либо всё, либо ничего
```

Голый забор, `text` и `txt` — плоская форма, `.nohl`: она и нужна выводу
команды:

```text
$ go build ./...

```

### Запуск с несколькими командами {#run-modes}

Сниппет с `actions=`: один листинг под двумя командами песочницы и
переключатель в тулбаре, который выбирает, что запустит Run. Тело — транскрипт
обеих, вторая часть открывается своей строкой `$ `. Песочницы за демо нет (см.
`params.codapi` в его конфиге), поэтому Run покажет состояние ошибки;
переключатель, части и вид без JS настоящие.

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var n int
	var wg sync.WaitGroup
	for range 2 {
		wg.Add(1)
		go func() { defer wg.Done(); n++ }()
	}
	wg.Wait()
	fmt.Println(n)
}
```

Записанная ошибка бывает и у действия: `error=` называет команды, чья часть —
ошибка. Здесь вторая команда запускает листинг прошлой версией Go, которая его
не компилирует, и её часть сразу читается в «провальном» цвете, как первая
часть при `error="true"`.

```go
package main

import "fmt"

type List[T any] []T

func (l List[T]) Map[U any](f func(T) U) List[U] {
	out := make(List[U], 0, len(l))
	for _, v := range l {
		out = append(out, f(v))
	}
	return out
}

func main() {
	fmt.Printf("%q\n", List[int]{1, 2, 3}.Map(func(n int) string { return fmt.Sprint(n) }))
}
```

## Выделения в тексте {#emphasis}

> [!epigraph] Роб Пайк, [Go Proverbs](https://go-proverbs.github.io/), 2015
> Clear is better than clever.
>
> Ясное лучше умного.

Раздел может открываться эпиграфом — единственным блоком, набранным курсивом
целиком: он сдвинут вправо, источник — моно-строкой. Всё ниже — обычный
Markdown, тот же исходник Obsidian читает без плагинов.

Заголовок слайса — три слова, и `append` может переселить массив за ними, а
может и не переселить. Отсюда правило чтения чужого кода:

>> После `append` все старые заголовки на тот же массив — под подозрением.
{#append-rule}

Цитата остаётся чужими словами — курсив, на тон тише, — а её черта стоит на
той же вертикали, что и знак тезиса:

> Don't communicate by sharing memory, share memory by communicating.
>
> — Go Proverbs

>> Тезис может занять два абзаца: пустая строка между ними — тоже `>>`.
>>
>> Шрифт прямой, цвет — как у текста, **жирный** и *курсив* внутри работают.

> [!aside]
> К слову, заголовок передаётся по значению — поэтому `append` внутри функции
> не виден в `len` у вызывающего, и поэтому [правило выше](#append-rule)
> работает.

> [!recap] чекпоинт
> Теперь вы по сигнатуре функции скажете, может ли она нарастить ваш слайс на
> месте.

Выделения внутри строки — маленькие: **жирный** — термин в момент определения
или зачин абзаца, *курсив* — одно-три слова интонации, *italic* и в латинице.

## Fold {#fold}

Сворачиваемая врезка — значок, заголовок и переключатель; панель выезжает по
высоте. `title=` — инлайновый Markdown, тело — Markdown.

{{< fold icon="video" title="У этого гайда есть также [видео-версия](https://youtu.be/dQw4w9WgXcQ)." >}}
Сначала посмотрите, потом прочитайте для закрепления — что-то нагляднее на
экране, что-то лучше усваивается текстом. Ссылка выше открывает видео **не**
сворачивая панель.
{{< /fold >}}

{{< fold icon="tip" title="Упрощение, сделанное намеренно." >}}
На самом деле всё чуть сложнее, но упрощённая модель верна в главном —
детали дальше.
{{< /fold >}}

{{< fold icon="code" more="Показать код" less="Скрыть" open="true" title="Полный листинг, сразу раскрытый." >}}
```go
func main() { println("hello") }
```
{{< /fold >}}

Примерно за полэкрана текста кат сам меняет регистр: заголовок набирается
читательским кеглем, блок получает свой воздух, а панель закрывается явной
кнопкой — длинное отступление можно свернуть там, где кончилось чтение.
`size=` задаёт регистр принудительно; здесь — чтобы показать секцию, не
вставляя стену текста.

{{< fold icon="book" size="section" title="Ликбез: отступление, выросшее в главу" more="Развернуть" >}}
Отступление на несколько экранов — уже не сноска, и набирать его двумя
кеглями ниже значит наказывать читателя за то, что он открыл: клик — это и
есть его согласие читать.

Поэтому раскрытая панель набрана прозой — тем же кеглем и цветом, что статья
вокруг, — а «это вставка» говорит структура: строка-заголовок, рельс слева и
строка-выход внизу.

Рельс — единственное, что переживает прокрутку. За первым экраном заголовок
уже уехал, и линия остаётся единственным признаком того, что вы всё ещё
внутри блока, который статья предложила пропустить.
{{< /fold >}}

## Термины {#terms}

Наведи на подчёркнутое слово — определение раскроется карточкой; клик её
закрепит, чтобы можно было спокойно читать и уйти по ссылке. Без JavaScript
все определения лежат списком в конце страницы, и каждое слово ведёт к своему.

Простейшая форма — слово и определение, тип по умолчанию:
у каждого P есть свой {{< term "mcache" >}}
Пер-P кэш мелких объектов. Аллокация из него идёт **без единого атомика** —
в этом весь смысл: быстрый путь не трогает разделяемое состояние.
{{< /term >}}, и попадание в него — самый дешёвый путь аллокации.

С ярлыком и цветом типа, и с ссылкой в подвале карточки:
компилятор вставляет {{< term word="барьер записи" title="Барьер записи" kind="ловушка" color="copper" href="/inside/anatomy/palette-is-a-file/" more="Разбор: барьеры и GC" >}}
Кусок кода, который рантайм вставляет **перед каждой записью указателя** в кучу,
пока GC работает конкурентно.

```go
// упрощённо: runtime/mbarrier.go
func writePointer(slot *unsafe.Pointer, ptr unsafe.Pointer) {
	shade(*slot)        // старое значение — в серые
	*slot = ptr
}
```

Отсюда правило: «указатель, записанный при работающем GC, не может быть потерян».
{{< /term >}} — и именно поэтому у записи указателя цена выше, чем у записи `int`.

Тело определения проходит тот же конвейер, что и статья, поэтому листинг
внутри карточки подсвечен ровно так же, как был бы в прозе:
путь пишется как {{< term word="JSON Pointer" kind="определение" color="blue" href="https://www.rfc-editor.org/rfc/rfc6901" more="RFC 6901" >}}
Стандарт адресации одного значения внутри JSON-документа — строка из токенов
через слэш:

```json
{
  "items": [
    {"price": 123},
    {"price": 101}  // это /items/1/price
  ]
}
```

Слева направо: поле `items`, элемент `1`, поле `price`.
{{< /term >}}, а не как путь через точки.

Слово в тексте склоняется, а шапка карточки — нет; для этого `title=`:
данные лежат в {{< term word="кэшах ядра" title="Кэш процессора" kind="железо" color="green" >}}
Три уровня — L1, L2, L3. Чем ближе к ядру, тем меньше и быстрее:

- **L1** — десятки килобайт, ~4 такта
- **L2** — сотни килобайт, ~12 тактов
- **L3** — мегабайты, общий на сокет, ~40 тактов

Промах мимо L3 стоит поход в память — это сотни тактов, и именно его
прячет за собой слово «локальность».
{{< /term >}}, а не в оперативке.

Определение — это блочный Markdown, поэтому схема ложится в него так же, как в
статью: та же разметка диаграмм, целиком захваченная `{{</* raw */>}}`. Карточка
под неё расширяется:
слайс — это {{< term word="заголовок из трёх слов" title="Заголовок слайса" kind="раскладка" color="gold" >}}
Три машинных слова, всегда в этом порядке:

{{< raw >}}
<div class="header">
  <div class="header-word ptr"><span class="wk">ptr</span><span class="wv">0x1040</span></div>
  <div class="header-word"><span class="wk">len</span><span class="wv">4096</span></div>
  <div class="header-word"><span class="wk">cap</span><span class="wv">8192</span></div>
</div>
{{< /raw >}}

Переслайсивание двигает `len` и `cap`; `ptr` съезжает только при росте за
`cap` — поэтому один слайс умеет писать сквозь другой.
{{< /term >}}, а не растущий массив.

## Превью ссылок {#link-previews}

На точном курсоре наведи на любую ссылку ниже — появится карточка-превью:
физика терм-карточки, один поповер, собранный из билд-фрагмента (внутренние
ссылки) или из пререндеренной карточки (Telegram, YouTube).

Внутренние ссылки открывают окно в страницу: превью целого
[гайда](/inside/anatomy/guide-is-a-bundle/), [якорь на раздел](/inside/anatomy/guide-is-a-bundle/#bundle),
который сужает карточку до одного раздела, и [оглавление серии](/inside/anatomy/)
со списком частей.

Telegram — пост из авторского канала получает карточку, собранную на билде:
[пост 409](https://t.me/ntuzov/409) и [пост 410](https://t.me/ntuzov/410).
[Несуществующий пост](https://t.me/ntuzov/99999) деградирует до карточки канала,
а [чужой канал](https://t.me/telegram/999) получает только значок ✈, без карточки.

YouTube — [доклад про планировщик Go](https://www.youtube.com/watch?v=kedW1xO3Zbo)
открывает видео-карточку с превью-кадром, длительностью и числом просмотров.

Обычная [внешняя ссылка](https://go.dev/blog/) несёт только значок ↗.

Википедия — [work-stealing планировщик](https://en.wikipedia.org/wiki/Work_stealing)
и [вытесняющая многозадачность](https://ru.wikipedia.org/wiki/Вытесняющая_многозадачность)
открывают карточку-сводку из REST API Wikimedia, со значком W.

Блог Go — [превью области видимости переменной цикла](https://go.dev/blog/loopvar-preview)
и классический [error handling in Go](https://go.dev/blog/error-handling-and-go)
открывают карточку с курсивным значком Go, байлайном и зачином поста.

## Рассылка {#newsletter}

Блоки подписки — на сайте, где рассылка включена (`params.newsletter.enable`,
см. [newsletter.md](https://github.com/justskiv/taiga/blob/main/docs/ru/newsletter.md)).
За ними в демо нет эндпоинта, поэтому отправка заканчивается состоянием ошибки —
на неё как раз и стоит посмотреть.

Срединный блок, поставленный руками, с крестиком (`dismiss=`), решение по
которому запоминается по блоку:

{{< newsletter label="серия · продолжение" dismiss="ks-demo" note="Демо-форма: за ней нет эндпоинта." >}}
Здесь гайд приводит свой довод в пользу письма — своим голосом, а не голосом темы.
{{< /newsletter >}}

Голая форма для страницы, написанной прозой (`newsletter-inline`) — тот же
компонент, что стоит на странице подписки:

{{< newsletter-inline note="Демо-форма: за ней нет эндпоинта." >}}

Карточка в подвале этой страницы — третий вариант, `newsletter-cta`; здесь её
вставил автоматически `placements.articleEnd`.
